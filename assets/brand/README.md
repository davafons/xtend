# Xtend brand assets

Sprout Buddy is the app icon: a round ivory seedling with two leaf-green leaves, two charcoal eyes, and two
small feet. It's a sibling of Parcela's Fence Buddy, and stands for tending relationships.

| File | Purpose |
| --- | --- |
| [`sprout-buddy.png`](sprout-buddy.png) | The generated master, 1254×1254 with a transparent background. |
| [`sprout-buddy-prompt.json`](sprout-buddy-prompt.json) | The exact image generation prompt. |
| [`../../public/icon.png`](../../public/icon.png) | 512×512 favicon and PWA icon, transparent. |
| [`../../public/icon-maskable.png`](../../public/icon-maskable.png) | 512×512 maskable PWA icon on Dim (`#15202b`), art inside the safe zone. |
| [`../../public/apple-touch-icon.png`](../../public/apple-touch-icon.png) | 180×180 home-screen icon on Dim. |
| [`../../extension/icons/`](../../extension/icons/) | 16, 32, 48 and 128 px extension icons, transparent. |

The sizes are crops and resizes of the master, centered on the art's bounds; nothing is redrawn or traced.
The master came from Codex's built-in image generation, with Fence Buddy as a style reference only.
