xtend Capture

Copies the responses x.com already loads for timelines, search, profiles, threads, likes, bookmarks, and follow lists, and sends them to Xtend. It never sends requests to X and never reads DMs.

Xtend opens for you to approve. The extension can then only send what x.com loads; it can't read anything back.

Use a pasted token instead

Create one in Xtend under X data → Browser extension.
